Inventory Movement Parser - Dr Mourad Sadek Pharmacies

Files:
- index.html: standalone mobile-friendly app.

Use:
1) Open index.html in a modern browser with internet access.
2) Upload the E-Pharmacy Plus "حركة أصناف حسب اليوم" PDF report.
3) Wait for all pages to be processed.
4) Filter by product, employee, movement type, or date.
5) Export the visible results to Excel.

GitHub Pages:
1) Upload index.html to the root of a GitHub repository.
2) Rename it to index.html if needed.
3) In Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4) Use the published Pages URL in Google Sites: Insert > Embed > By URL.

Notes:
- PDF.js and SheetJS load from public CDNs, so an internet connection is required.
- Files are processed in the browser; this app does not upload the PDF to a server.
- Always compare exported records with the source report before relying on them operationally.
